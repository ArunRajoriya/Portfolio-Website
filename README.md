## 🚀 Quick Deploy

### Prerequisites

- Node.js v18+
- npm v9+

### Deploy in 3 Steps

1. **Install dependencies:**

   ```bash
   npm install
   ```

2. **Build for production:**

   ```bash
   npm run build
   ```

3. **Deploy:**
   - **Cloudflare Pages**: Connect GitHub repo, build command: `npm run build`, output: `.output/public`
   - **Vercel**: Import repo, framework: TanStack Start, auto-deploy
